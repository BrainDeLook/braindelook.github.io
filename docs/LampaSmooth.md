# Lampa Smooth 0.2.0-beta.1

Небольшой отдельный плагин для сокращения повторных расчётов при навигации с пульта. Не меняет CSS, постеры, фон, размытие, анимации или настройки Lampa. Можно использовать вместе с Apple TV interface.

Адрес для подключения в расширениях Lampa:

`https://braindelook.github.io/LampaSmooth.min.js`

После добавления полностью перезапустите Lampa. Для отката отключите или удалите только Lampa Smooth и перезапустите приложение.

## Что ускоряется

Контроллеры Lampa часто вызывают `Navigator.canmove(direction)`, а затем сразу `Navigator.move(direction)`. Оба вызова ищут соседний элемент: читают геометрию коллекции, проверяют видимость и сортируют кандидатов.

Плагин передаёт уже найденную карточку второму вызову. Сам переход, события фокуса и обработчики расширений выполняет исходный движок. Это применяется к контроллерам главной страницы, каталога, меню и карточки, использующим такую пару вызовов. Одиночный `move()` работает как раньше.

Результат сохраняется только до ближайшей микрозадачи. При изменении DOM, коллекции, фокуса, направления, параметров навигации или положения окна выполняется обычный поиск. Для виртуальных прямоугольников и пользовательских фильтров оптимизация пропускается. Постоянного наблюдателя за DOM нет: он включается только на короткий промежуток между проверкой и переходом.

## Проверка 10 ноября 2026

Реальное устройство: Box R 4K Plus, Android 12, Lampa 1.13.5, сайт lampa.mx. Одинаковая последовательность из 12 переходов по прогретым постерам, без записи экрана:

| Экран | Вызовы расчёта геометрии без плагина | С плагином |
| --- | ---: | ---: |
| Ряд главной страницы | 192 | 96 |
| Каталог из 20 карточек | 480 | 240 |

Число вычислений уменьшилось вдвое в этом сценарии. Это не означает удвоение FPS: на плавность также влияют отрисовка фона, WebView, загрузки и другие плагины. Стабильного роста частоты кадров эти короткие замеры не доказывают.

В Chromium и WebKit проверены совпадение результата навигации, событий focus/unfocus и пикселей статической сцены, а также сброс результата после изменения DOM, коллекции, направления и параметров, перехода к следующей микрозадаче, отключения и повторного включения. Проверена минифицированная ES5-сборка.

Это beta для проверенного варианта SpatialNavigator в lampa.mx. Если контракт движка отличается или нужные браузерные API отсутствуют, плагин не включается. Проверка WebKit на компьютере не заменяет испытание на физическом Apple TV/Luxo; старые Tizen и webOS отдельно не проверены.

## Файлы

- `LampaSmooth.min.js` — файл для установки.
- `LampaSmooth.js` — читаемый исходник.

Для временной диагностики через консоль доступны `LampaSmooth.disable()` и `LampaSmooth.enable()`. Плагин сам не выполняет сетевые запросы и не сохраняет пользовательские данные.
